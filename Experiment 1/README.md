## 文件分工

- `TriangleQuestion.h`：类的声明。
- `TriangleQuestion.cpp`：成员函数的定义。
- `main.cpp`：生成对象并调用成员函数。
- `Experiment1_TriangleQuestion.sln`：Visual Studio 解决方案。

## 本实验使用的知识

- 类与对象
- `private` 和 `public` 访问控制
- 数据成员和成员函数
- 默认构造函数、重载构造函数、析构函数
- 对象调用成员函数
- 三角形三边合法性验证


## 与指导书步骤的对应关系

1. 设计三个私有数据成员 `sideA`、`sideB`、`sideC`。
2. 使用公有成员函数完成修改、获取、输出和合法性验证。
3. 默认构造函数生成三边为 3、4、5 的对象。
4. 重载构造函数按传入的三条边生成对象。
5. 在 `main.cpp` 中分别生成对象并调用周长、面积和类型判断功能。
