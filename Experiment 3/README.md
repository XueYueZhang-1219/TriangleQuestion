# 实验三 继承与派生

本工程依据实验指导书“实验三 继承与派生”的题目一完成，并从小学数学练习系统最终成品中反向拆分出当前阶段允许使用的功能。

## 本实验完成的功能

- 用户输入本次练习题数量，范围为 1 到 10。
- 程序随机生成正方形、长方形、圆形、三角形或梯形题目。
- 用户输入每道题的面积和周长答案。
- 程序判断答案、汇总成绩并显示答题回看。

## 类的设计

- `ShapeQuestion`：基类，保存题号、图形名称、用户答案、正确答案和作答状态。
- `SquareQuestion`、`RectangleQuestion`、`CircleQuestion`、`TriangleQuestion`、`TrapezoidQuestion`：五个派生类，保存各自特有的尺寸，并计算各自的面积和周长。
- `QuestionBank`：题库类，保留实验二的组合关系，内部包含五种派生类的固定对象数组。

五个派生类都采用公有继承，例如：

```cpp
class SquareQuestion : public ShapeQuestion
```

含义是“正方形题目是一种图形题目”，也就是 `is a` 关系。

## 为什么没有使用最终成品中的写法

最终成品使用了虚函数、多态、`vector`、模板、文件流和运算符重载。这些分别属于实验四及后续实验。本工程为了严格停留在实验三，只使用：

- 实验一的类、对象、封装、构造函数和成员函数；
- 实验二的组合关系、依赖关系和固定对象数组；
- 实验三新增的基类、公有继承和派生类。

因此题库没有使用 `ShapeQuestion*` 配合虚函数保存混合图形，而是分别保存五种派生类对象，再用两个普通整数数组记录题目种类和顺序。

## 文件分工

- `ShapeQuestion.h`：基类和五个派生类的声明。
- `ShapeQuestion.cpp`：基类和派生类成员函数的定义。
- `QuestionBank.h`、`QuestionBank.cpp`：题库类的声明与定义。
- `main.cpp`：生成题目、接收输入、显示回看和成绩。
- `Experiment3_Inheritance.sln`：Visual Studio 解决方案。

## 与指导书步骤的对应

1. 建立 `ShapeQuestion` 基类和五个派生类的结构。
2. 在基类中实现共同的答题、判题和结果显示功能。
3. 在派生类中增加各图形特有的尺寸数据，并实现各自的面积、周长和题目显示功能。
4. 在 `QuestionBank` 中创建并使用派生类对象，生成随机题目、完成作答、统计成绩和回看题目。

## Visual Studio 运行方法

1. 双击 `Experiment3_Inheritance.sln`。
2. 在工具栏选择 `Debug` 和 `x64`。
3. 选择“生成”中的“生成解决方案”。
4. 按 `Ctrl + F5` 运行。

如果中文显示异常，请确认项目属性中的编译选项包含 `/utf-8`。本项目文件已经写入该选项。
