# C++ 面向对象程序设计实验

本仓库包含两个 Visual Studio C++ 实验项目：

- [`Experiment 1`](./Experiment%201)：实验一——三角形题目类
- [`Experiment 2`](./Experiment%202)：实验二——题库系统（组合关系与依赖关系）

每个文件夹内都有独立的 Visual Studio 解决方案（`.sln`）、项目文件、源代码和实验说明。

## 打开方式

1. 在 Visual Studio 中选择“打开项目或解决方案”。
2. 进入相应实验文件夹。
3. 打开该文件夹中的 `.sln` 文件即可编译和运行。
